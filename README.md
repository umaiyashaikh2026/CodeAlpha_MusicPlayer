# Midnight FM 🎧

A handcrafted responsive music player using HTML, CSS and vanilla JavaScript.

Features: play/pause, previous/next, seek, volume/mute, shuffle, repeat, playlist drawer, keyboard controls, animated vinyl record, animated playback meter and responsive layout.

## Add audio
Put royalty-free or self-created MP3 files in `music/` named `song1.mp3` through `song4.mp3`. Do not upload copyrighted tracks you do not have permission to redistribute.
